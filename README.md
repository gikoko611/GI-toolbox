## Features

- 12 categories × 25 tools = **300 features** (Image, PDF, Text & Code, Converters, Calculators, Network & IP, QR & Barcode, Device & Sensor, Security & Privacy, Audio & Video, Utility, AI Tools)
- GI **3D gold logo** app icon
- Cyber theme UI: neon green + gold on dark, animated 3D cyber grid background
- Splash screen: GI logo + **POWERED BY I KO KO**
- Most tools run **fully offline** inside the app

## Build

APK ကို GitHub Actions နဲ့ auto-build ပါတယ် — push တိုင်း build ပြီး APK ကို artifact အနေနဲ့ တင်ပေးမယ်။

1. Push code → Actions tab → **Build GIToolbox APK** workflow runs
2. Download **GIToolbox-v1.0-debug-APK** artifact → unzip → install `app-debug.apk`

## Tech

- Android (Java) + WebView shell, single-activity
- UI: HTML/CSS/JS (offline, bundled in assets)
- Build: Gradle 8.7 + AGP 8.5.2, JDK 17
